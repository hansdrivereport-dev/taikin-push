퇴근 보고 알림

퇴근 보고(입관증·PC)를 아직 안 했을 때
이 폰으로 알림을 보내 드립니다.

설정이 필요합니다

관리자: config.js에 Firebase 설정, VAPID 키, Apps Script URL을 입력해 주세요.

브라우저에서 열어 주세요

카카오톡 안에서 연 화면에서는 알림을 등록할 수 없습니다.

  1. 오른쪽 위(또는 아래) ⋮ / 공유 메뉴를 누릅니다.
  2. 다른 브라우저로 열기를 누릅니다.
    아이폰은 Safari, 안드로이드는 Chrome으로 열어 주세요.

아이폰은 홈 화면에 추가가 필요합니다

아이폰은 홈 화면 아이콘으로 열어야 알림을 받을 수 있습니다. (iOS 16.4 이상)

  1. Safari 아래쪽 공유 버튼 을 누릅니다.
  2. 목록을 내려서 홈 화면에 추가를 누르고, 오른쪽 위 추가를 누릅니다.
  3. 홈 화면에 생긴 퇴근보고 아이콘으로 다시 열어 주세요.

이 기기에서는 알림을 받을 수 없습니다

안드로이드는 Chrome 최신 버전, 아이폰은 iOS 16.4 이상에서 홈 화면 아이콘으로 열어 주세요.

계속 안 되면 관리자에게 알려 주세요. 기존처럼 단체방 공지로 안내받게 됩니다.

알림 등록 완료

퇴근 보고를 하지 않은 날 저녁에 알림이 옵니다.
알림을 누르면 보고 폼이 바로 열립니다.
